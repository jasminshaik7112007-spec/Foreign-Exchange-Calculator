# Foreign-Exchange-Calculator

Key features include multi-currency conversion, updated exchange rates, currency search, currency comparison, conversion history, automatic rate refresh, and an interactive dashboard for quick and convenient calculations.
# Foreign Exchange Calculator

A Python and Streamlit-based web application designed to make international currency conversion simple, fast, and convenient. The application allows users to convert amounts between supported currencies using the latest exchange rates available through an external API.

## Features

- **User Authentication:** Secure user registration and login.
- **Currency Conversion:** Convert amounts between different supported currencies.
- **Live Exchange Rates:** View the latest available exchange rates.
- **Currency Search:** Search and explore supported currencies.
- **Currency Comparison:** Compare exchange rates between currencies.
- **Favourite Currencies:** Save frequently used currencies for quick access.
- **Rate Alerts:** Set alerts for preferred exchange rate values.
- **Exchange Rate Analytics:** Visualize exchange rate information through charts.
- **Conversion History:** View previous currency conversions.
- **PDF Reports:** Generate and download conversion reports.
- **User Profile:** Manage personal account details.
- **Dark and Light Mode:** Customize the application appearance.

## Technologies Used

- **Programming Language:** Python
- **Frontend:** Streamlit
- **API Integration:** Exchange Rate API
- **Database:** SQLite
- **Data Processing:** Pandas
- **Data Visualization:** Plotly
- **PDF Generation:** ReportLab
- **Development Tools:** Visual Studio Code, Git and GitHub

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/jasminshaik7112007-spec/Foreign-Exchange-Calculator.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Foreign-Exchange-Calculator
   ```

3. Install the required packages:

   ```bash
   python -m pip install -r SE_Requirements.txt
   ```

4. Run the Streamlit application:

   ```bash
   python -m streamlit run SE_project.py
   ```
